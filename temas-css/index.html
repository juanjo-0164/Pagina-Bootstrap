Resumen de los temas 2.1 a 2.9 con un ejemplo de cada uno. Los ejemplos están hechos con CSS de verdad, no son imágenes.

2.1 Estructura y sintaxis

Una regla de CSS tiene un selector, y entre llaves van las propiedades con su valor.

selector {
  propiedad: valor;
}

p {
  color: blue;
  font-size: 18px;
}

En el ejemplo el selector es p, las propiedades son color y font-size, y los valores son blue y 18px. Cada declaración termina en punto y coma.

Si se olvida el punto y coma o la llave de cierre, esa regla no funciona.

Selectores básicos:

  • p: todos los párrafos
  • .nota: todo lo que tenga class="nota"
  • #logo: el elemento con id="logo"

2.2 Tipos de incorporación

Va dentro de la etiqueta style en el head del mismo HTML.

<style>
  p { color: blue; }
</style>

Va en un archivo .css aparte y se conecta con link. Es el que más se usa.

<link rel="stylesheet" href="css/estilos.css">

Va directo en la etiqueta con el atributo style. Solo afecta a ese elemento.

<p style="color: blue;">Hola</p>

2.3 Identación, herencias y comentarios

Identación

Dejar espacios al inicio de las líneas para que el código se entienda mejor.

.caja {
  color: red;
  margin: 0;
}
Herencia

Los hijos heredan algunas propiedades del padre, como el color de la letra.

Soy el padre

Soy el hijo y tengo el mismo color, pero el borde no se heredó.

Comentarios

El navegador los ignora. Se escriben así:

/* comentario */
p {
  color: blue;
}

2.6 Media queries

Sirven para que la página se vea bien en celular, tablet y computador. Dice: si la pantalla es de tal ancho, aplica estos estilos.

.caja-color {
  background: red;
}

@media (min-width: 768px) {
  .caja-color {
    background: blue;
  }
}

Esta caja cambia de color cuando se cambia el ancho de la ventana:

Cambio de color
  • Menos de 576 px: rojo
  • Desde 576 px: naranja
  • Desde 768 px: azul
  • Desde 992 px: verde

2.7 Pseudo-elementos

Se escriben con dos puntos dobles. Sirven para darle estilo a una parte del elemento.

::before y ::after

Texto del medio

p::before { content: "[ "; }
p::after { content: " ]"; }
::first-letter

Esta es la primera letra de un párrafo.

p::first-letter {
  font-size: 2rem;
  color: red;
}
::first-line

La primera línea de este párrafo sale en negrita y de otro color, el resto se ve normal aunque se cambie el ancho de la ventana.

p::first-line {
  font-weight: bold;
  color: blue;
}
::selection

Selecciona este texto con el mouse.

p::selection {
  background: yellow;
  color: black;
}

2.9 Z-index

Cuando hay elementos encima de otros, el z-index decide cuál se ve arriba. El número más alto queda encima. Para que funcione el elemento tiene que tener position (relative, absolute, fixed o sticky).

.azul { position: absolute; z-index: 1; }
.amarilla { position: absolute; z-index: 3; }
.roja { position: absolute; z-index: 2; }
Azul 1
Amarilla 3
Roja 2

La amarilla queda arriba porque tiene el número más alto.

Bootstrap ya trae z-index para sus componentes: dropdown 1000, navbar sticky 1020, offcanvas 1045, modal 1055, popover 1070, tooltip 1080 y toast 1090.
