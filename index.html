2.1 Estructura y sintaxis

Qué es una regla

Una regla tiene un selector (a qué elemento) y propiedades entre llaves.

Ejemplo

p {
  color: blue;
  font-size: 18px;
}

Cada propiedad termina en punto y coma.

Selectores básicos

  • p: todos los párrafos
  • .nota: los elementos con class="nota"
  • #logo: el elemento con id="logo"

Error común

Si se olvida el punto y coma o la llave de cierre, la regla no funciona.

2.2 Tipos de incorporación

Interno

Va dentro de <style>, en el head del mismo HTML.

<style>
  p { color: blue; }
</style>

Externo

Va en un archivo .css aparte, conectado con <link>. Es la forma más usada.

<link rel="stylesheet" href="css/estilos.css">

En línea

Va directo en la etiqueta, con el atributo style. Solo afecta a ese elemento.

<p style="color: blue;">Hola</p>

2.3 Identación, herencia y comentarios

Identación

Son los espacios al inicio de cada línea. No cambian el resultado, pero hacen el código más fácil de leer.

.caja {
  color: red;
  margin: 0;
}

Herencia

El hijo recibe algunos estilos del padre, como el color de la letra.

Soy el padre

Soy el hijo: tengo su mismo color.

Comentarios

Son notas que el navegador ignora.

/* esto es un comentario */

2.4 Niveles de especificidad

Qué pesa más

Si dos reglas chocan, gana la de más peso.

TipoEjemplo
En líneastyle="..."
ID#titulo
Clase.nota
Etiquetap

Ejemplo

p { color: red; }
.nota { color: blue; }
#especial { color: green; }

Si el elemento tiene id="especial", se ve verde, porque el id pesa más.

Empates

Si las dos reglas tienen el mismo peso, gana la que está más abajo en el archivo.

2.6 Media queries

Idea

Aplican un estilo solo si la pantalla tiene cierto ancho.

Ejemplo

.caja {
  background: red;
}

@media (min-width: 768px) {
  .caja {
    background: blue;
  }
}

2.7 Pseudo-elementos

Dan estilo a una parte del elemento, sin tocar el HTML.

::before y ::after

Texto del medio

p::before { content: "[ "; }
p::after { content: " ]"; }

::first-letter

Esta es la primera letra de un párrafo.

p::first-letter {
  font-size: 2rem;
}

::selection

Selecciona este texto con el mouse.

p::selection {
  background: yellow;
}

2.8 Pseudo-clases

Cambian el estilo según el estado del elemento.

:hover

Se activa al pasar el mouse por encima.

button:hover {
  background: orange;
}

:focus

Se activa al hacer clic en un campo.

input:focus {
  background: lightyellow;
}

:first-child y :last-child

  • Primero
  • Segundo
  • Tercero
li:first-child { color: green; }
li:last-child { color: red; }

2.9 Z-index

El z-index decide qué elemento queda encima cuando dos se montan. El número más alto queda arriba.

Ejemplo 1: capas

Mueve el control y mira cómo cambia la caja roja:

Azul
Roja
z-index de la roja 1

Con 3 o 4, la roja queda encima de la azul. Con 1, queda debajo.

.azul { position: absolute; z-index: 2; }
.roja { position: absolute; z-index: 1; }

Ejemplo 2: sin position, no funciona

La caja de arriba tiene z-index: 5, pero no tiene position. Por eso la caja de abajo, que sí tiene position: relative, queda encima.

z-index: 5, sin position
position: relative, z-index: 1
.sin-position { z-index: 5; }
.con-position { position: relative; z-index: 1; }
